# steinerartisanfarm.github.io
Independent information page about Steiner Artisan Farm, hosted on GitHub Pages.

The static site is published from `docs/`. Its banner uses `docs/images/logo.jpg`
and `docs/images/lisa_wagon_2.jpg`, with `docs/images/lisa_dog.jpg` displayed as a
circular profile portrait. The page includes a neutral introduction and a
first-person lending testimonial attributed to the site owner; it is not the
farm's official website.

To preview the site locally, run `python3 -m http.server 8000 --directory docs`
from the repository root and open `http://localhost:8000/`.
